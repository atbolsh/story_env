# Minimal runtime deps for Python 3.12 / Django 5.2 LTS.
#
# This used to be the original Park et al. 2023 `pip freeze` dump (~70 pins),
# but most of those pins were either (a) Heroku-deploy leftovers
# (gunicorn, psycopg2-binary, boto*, dj-database-url, s3transfer),
# (b) paper-analysis tools that nothing in the live code path imports
# (gensim, seaborn, statsmodels, yellowbrick, scikit-posthocs, trueskill,
# scipy, sklearn, nltk, matplotlib, Pillow, pandas), or (c) transitive
# deps of those + of openai/selenium (aiohttp, aiosignal, frozenlist,
# multidict, yarl, trio*, wsproto, h11, ...). Trimming them was necessary
# to get a clean pip resolution on Python 3.12 -- numpy 1.25.2 and
# aiohttp 3.8.3 (among others) have no cp312 wheels and fail to build
# from source against modern setuptools/pkgutil.
#
# If you ever want the analysis stack back, install it on top:
#   pip install pandas scipy scikit-learn matplotlib seaborn statsmodels

# --- Web frontend ---
# Django 5.2 LTS officially supports Python 3.10-3.13 and is supported
# through April 2028. The 2.2 -> 5.2 jump required three mechanical fixes
# in this repo (re_path in urls.py, `{% load static %}` in templates,
# dropping a dead staticfiles import in views.py); see git history.
Django>=5.2,<5.3
django-cors-headers>=4.3
django-storages>=1.14          # replaces the dead `django-storages-redux` fork

# --- Backend numerics ---
# numpy 1.26 was the first release with cp312 wheels. The repo only uses
# dot, linalg.norm, array, std -- all stable on 1.26-2.x.
numpy>=1.26

# --- LLM API ---
# 0.28 is the last 0.x release; it still exposes the legacy
# `openai.api_key = ...` / `openai.ChatCompletion.create` / `openai.Embedding.create`
# surface that this codebase uses. Migration to openai>=1.0 is tracked as
# a separate task (see KNOWN_TECHNICAL_WEAKNESSES.md sec. 3.9).
openai>=0.28.0,<1.0

# --- Misc ---
# Sourced by run_remote_servers.sh; useful once we wire local-model
# selection (or any other config) through .env in Python.
python-dotenv>=1.0

# --- Local Gemma 4 harness (reverie/backend_server/harnesses/gemma4.py) ---
# Only needed when REVERIE_HARNESS is set to gemma4-e2b or gemma4-e4b;
# legacy-gpt mode does NOT need any of these. Versions mirror the smoke
# tests in ../test-gemma4/requirements.txt.
#
# NOTE: on hosts with NVIDIA driver < 580 (i.e. CUDA <= 12.x), do NOT take
# the default pip wheel for torch -- it pulls a cu13 build that can't see
# the GPU. Install explicitly from the CUDA 12 index, e.g.:
#   pip install -U "torch>=2.7" torchvision torchaudio \
#       --index-url https://download.pytorch.org/whl/cu124
torch>=2.7.0
torchvision>=0.22.0
# Gemma 4 requires a recent transformers (AutoModelForMultimodalLM, gemma4
# arch); 4.57.x does NOT have it.
transformers>=4.60.0
accelerate>=1.0.0
safetensors>=0.4.0
huggingface_hub>=0.30.0
# Local retrieval embedder used by the Gemma 4 harness (BAAI/bge-small-en-v1.5).
sentence-transformers>=3.0
einops>=0.7.0
